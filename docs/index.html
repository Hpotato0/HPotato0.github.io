About

I am a third-year PhD student at Georgia Tech advised by Prof. Moinuddin Qureshi. My research focuses on computer architecture and systems for AI workloads. My recent work includes data movement optimization in CPU-GPU systems for LLM inference, GPU memory system design for emerging memory technologies such as High-Bandwidth Flash, and efficient mixture-of-experts inference.
